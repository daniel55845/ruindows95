## Ruindows95

Este é o meu sistema operacional, criado com o humilde objetivo de acabar com a hegemonia do Linux Mint e do Hannah Montana Linux no mundo das distribuições Linux.

O Ruindows95 é baseado no Arch Linux, utilizando o kernel LTS para maior estabilidade e a interface gráfica XFCE com o [Chicago95](https://github.com/grassmunk/Chicago95) como tema principal, trazendo de volta a clássica estética dos anos 90.

Utilizei o Bauh como gerenciador de aplicativos, permitindo instalar os softwares que você quiser de forma visual e Nutella, sem precisar recorrer ao terminal para tudo. Ele oferece suporte aos repositórios oficiais do Arch Linux, Flatpak e AppImage.

O sistema também conta com alguns aplicativos pré-instalados, como Steam, Firefox, VLC, calculadora, visualizador de imagens, gerenciador de discos e outras ferramentas úteis para o dia a dia.

Além disso, possui sons personalizados, animação de inicialização, instalação offline e ferramentas para facilitar a configuração dos drivers.

A proposta é combinar a liberdade do Arch Linux, a facilidade de uso do Linux Mint e a beleza questionável dos sistemas operacionais dos anos 90.

## Download

**[Baixar Ruindows95 V10.8.2 LTS](https://github.com/daniel55845/ruindows95/releases/tag/v10.8.2)**

Devido ao limite de tamanho dos arquivos do GitHub, a ISO foi dividida em duas partes. É necessário baixar ambas e colocá-las na mesma pasta.

### Como juntar as partes no Linux

Abra o terminal na pasta onde os arquivos foram baixados e execute:

```bash
cat ruindows95.iso.part-* > ruindows95.iso
```

### Como juntar as partes no Windows

Abra o Prompt de Comando (CMD) na pasta onde os arquivos foram baixados e execute:

```cmd
copy /b ruindows95.iso.part-00+ruindows95.iso.part-01 ruindows95.iso
```

Após juntar as duas partes, você terá a ISO completa, chamada `ruindows95.iso`.

Utilize o Rufus, Ventoy ou Balena Etcher para preparar um pendrive inicializável. Também é possível testar o sistema em uma máquina virtual, utilizando VirtualBox ou QEMU/KVM.

O instalador será aberto automaticamente após o carregamento da interface gráfica.
